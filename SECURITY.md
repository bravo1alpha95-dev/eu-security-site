# Security Considerations — eu-security-site

This repository is a static documentation site. It contains no backend, no forms that submit data, and no third-party scripts.

## Reporting vulnerabilities

Please report security issues privately to **bravo1alpha95@gmail.com**. Do not open a public issue for a vulnerability.

## Notes

- GitHub Pages is not enabled. Enabling it would publish the site.
- Do not add tracking scripts, webfonts that phone home, or invented claims about EmpowerU LLC.
