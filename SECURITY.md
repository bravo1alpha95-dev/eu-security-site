# Security Considerations — eu-security-site

This repository is a static documentation site. It contains no backend and no third-party scripts. The Pricing and pilot page has a first-party form that opens a pre-filled `mailto:` message in the visitor's email app; nothing is posted to this site or to a server we operate.

## Reporting vulnerabilities

Please report security issues privately to **bravo1alpha95@gmail.com**. Do not open a public issue for a vulnerability.

## Notes

- The site is public on GitHub Pages; every merge to `main` republishes it. Review changes with that in mind.
- Do not add tracking scripts, webfonts that phone home, or invented claims about EmpowerU LLC.
