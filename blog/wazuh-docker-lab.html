Setting up the Wazuh Docker lab

The eu-wazuh-detections repository ships a small Docker lab: one Wazuh manager and one Wazuh agent, both 4.14.10, with the EmpowerU custom rules mounted into the manager. It is a disposable test bed, not a production install. The full step-by-step guide is docs/SETUP-WAZUH-LAB.md; this tutorial is the short version.

Lab only The lab's enrollment service accepts agents without a password, and there is no indexer or dashboard. Do not publish ports 1514, 1515, or 55000 to the internet.

What you need

  • A Linux or Mac computer you own with Docker Engine or Docker Desktop, Docker Compose v2 (docker compose version), and Git.
  • About 2 CPUs and 2–4 GB of free RAM.
  • Free host ports 1514, 1515, and 55000.

1. Start the lab

git clone https://github.com/bravo1alpha95-dev/eu-wazuh-detections.git
cd eu-wazuh-detections/lab
docker compose up -d

If Docker says "permission denied" on /var/run/docker.sock, put sudo in front of the docker commands. The first run pulls the official images.

2. Wait for the agent

docker exec wazuh-lab-manager /var/ossec/bin/wazuh-control status
docker exec wazuh-lab-manager /var/ossec/bin/agent_control -l

Continue when the agent shows as Active, for example ID: 001, Name: wazuh-lab-agent, IP: any, Active.

3. Confirm the rules loaded

docker exec wazuh-lab-manager grep -E 'Total rules|ERROR|error:|eu_ec' /var/ossec/logs/ossec.log | tail
docker exec wazuh-lab-manager ls -la /var/ossec/etc/rules/ /var/ossec/etc/decoders/

You should see eu_ec_detect_rules.xml and eu_ec_detect_decoders.xml, and no rule-parse errors.

4. Fire the file-integrity rules

./fim-test.sh

The script touches /usr/bin/ls and appends a comment to /etc/ssh/sshd_config inside the agent container. You should see leaf alerts 100020 and 100021 at level 12 in /var/ossec/logs/alerts/alerts.json on the manager. Both fired this way on a live 4.14.10 lab on 2026-11-13. See Simulating detections safely for what each step does.

5. Tear down

docker compose down      # stop; keep volumes
docker compose down -v   # also wipe lab data

Troubleshooting, briefly

  • Agent cannot resolve or reach the manager. The compose file maps wazuh-lab-manager to the Docker host gateway and publishes 1514/1515. Check docker ps and that nothing else holds those ports.
  • Only rule 554 appears. The file was new, not modified. Modify it again after a scan has finished.
  • Rules mounted after analysisd started. Run docker restart wazuh-lab-manager.

For a full single-node server with indexer and dashboard, the setup guide links to the official Wazuh Quickstart and its hardware requirements (4 vCPU, 8 GiB RAM, and 50 GB of storage for up to 25 agents).
