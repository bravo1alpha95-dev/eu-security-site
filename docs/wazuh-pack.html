Wazuh detections pack

Source: eu-wazuh-detections. Defensive rules for a Wazuh manager you operate, derived from the community collector’s detections.

Not tested on a live manager wazuh-logtest was not available when this pack was published. The rules have not been tested against a live Wazuh manager. Parent rule IDs come from default Wazuh rule sets and can vary by version. Validate every rule with wazuh-logtest on your manager before you rely on the alerts.

Dashboard

dashboards/eu-ec-detect-starter.ndjson is a starter saved-object export for Wazuh Dashboard / OpenSearch Dashboards. It is labeled untested. Import may need adjustments for your Wazuh and OpenSearch versions, index pattern, and time field. A successful import is not validation of the detection rules.

Install outline

  1. Back up the manager and take a snapshot.
  2. Copy rules/eu_ec_detect_rules.xml to the manager custom-rules directory (commonly /var/ossec/etc/rules/).
  3. Run wazuh-logtest against representative log lines for your Wazuh version. Confirm parent SIDs (530, 550, 5501, 5503, 5710, 5715) still mean what the pack assumes.
  4. Reload the manager only after that review, under your own change control, on a system you own.

The installer can copy the rules in dry-run (--check) first. It will not restart the manager.
