Quick start

The community collector lives in eu-ec-detect-community. It is read-only by default and only for systems you own.

One-time setup

  1. Clone the repository to an operator host you control. 
    git clone https://github.com/bravo1alpha95-dev/eu-ec-detect-community.git
cd eu-ec-detect-community
  2. Create a local environment file and restrict its mode: 
    cp .env.example .env && chmod 600 .env
  3. Edit .env. Set EU_SCOPE_CIDR to the authorized address range of systems you own. The example value 10.0.0.0/24 is a placeholder, not a network you should assume is yours.
  4. Fill scope/inventory.md with hosts you own, and fill every (fill) field in the Rules of Engagement template scope/roe.md. Set Status: AUTHORIZED only when you have written authorization. Collection itself is read-only and does not require that status; the apply path does.
  5. Run the one-command path: 
    ./scripts/easy-run.sh

That command runs preflight, a full access-evidence collection, and a short summary. Nothing on the host is changed. Review the timestamped files under reports/ before you share them. Reports are gitignored; do not commit them.

Ongoing use

  • Re-run ./scripts/easy-run.sh whenever you want a fresh snapshot, or schedule it with cron or systemd.
  • Run ./scripts/anomaly-checks.sh to compare current listeners against a per-host baseline with a checksum sidecar.
  • Do not run ./scripts/20_apply.sh with CONFIRM=yes until the ROE is complete. Even then, that script only writes a local Wazuh agent config stub and prints install commands for you to run after you verify vendor artifacts yourself. This project does not ship vendor GPG fingerprints.

Checks before you change the code

for script in scripts/*.sh; do bash -n "$script" || exit; done
shellcheck -x scripts/*.sh
python3 tests/test_regressions.py

The regression suite has 32 tests, plus a community hygiene check. GitHub Actions runs the same commands.

To copy the toolkit onto a host with a dry-run installer, see the installer. To add starter Wazuh rules, see the Wazuh pack.
