Installer

Source: eu-monitor-installer. Copies the community toolkit, and optionally the Wazuh rules, onto a host you own. It does not install Wazuh packages, import GPG keys, enable systemd timers, or restart a manager.

One command, dry-run by default

# Print the plan; write nothing
./install.sh

# Include Wazuh rules in the plan
./install.sh --with-wazuh-rules

# Apply only with an authorized ROE
CONFIRM=yes ./install.sh --prefix /opt/eu-ec-detect --roe /path/to/authorized-roe.md

CONFIRM=yes without a completed Rules of Engagement file (Status: AUTHORIZED and every (fill) field set) is refused. Existing scope/roe.md and scope/inventory.md at the destination are not overwritten.

Ansible

cd ansible
# Dry-run
ansible-playbook site.yml --check

# Apply
ansible-playbook site.yml -e eu_monitor_confirm=yes -e eu_monitor_roe_path=/path/to/authorized-roe.md

Copy inventory/hosts.example.yml to inventory/hosts.yml and replace the 10.0.0.10 placeholder with a host you own. The example inventory is not a real target list.

Docker

A helper image runs the read-only easy path inside the container. It does not, by default, monitor the host.

docker compose build
docker compose run --rm eu-collect

Reports go to a named volume. CONFIRM is never set in the Compose file. The image runs as a non-root user, drops capabilities, and uses a read-only root filesystem.

About validation of the image Docker was not available in the environment that first published this repository, so docker build was not run there. The Dockerfile is written for Debian bookworm-slim with GNU sed. Build and review it on a machine you control before use.

After the files are in place

Follow the quick start in the installed prefix: copy .env.example to .env, set EU_SCOPE_CIDR, fill the inventory and ROE, and run ./scripts/easy-run.sh. Example systemd units are copied into $prefix/systemd and are not enabled by the installer.
