Defensive monitoring tools you can run on systems you own.

EmpowerU LLC publishes a small set of open-source tools for access monitoring, evidence collection, and starter Wazuh detections. They are read-only by default, dry-run until you explicitly confirm, and limited to authorized, owned systems.

The tools

Three companion repositories make up the public-ready toolkit. They are described only in terms of what the software actually does. This site does not offer a managed service, a certification, or a sales claim.

eu-ec-detect-community

Bash toolkit that collects access evidence (users, logins, SSH and sudo excerpts, listeners), compares listeners to a baseline, and redacts secrets in reports. Dry-run / read-only by default.

View the repository

eu-wazuh-detections

Custom Wazuh rules (IDs in the 100000+ range), optional decoders, and a starter dashboard derived from those detections. The rules have not been tested with wazuh-logtest against a live manager.

View the repository

eu-monitor-installer

One-command ./install.sh, Docker Compose, and an Ansible playbook that copy the toolkit (and optionally the Wazuh rules) onto a host you own. Dry-run and --check are the defaults.

View the repository

Operating principles

  • Defensive only, owned systems only. The tools do not target third-party systems and do not include offensive techniques.
  • Dry-run by default. Collection is read-only. Any mutation requires both CONFIRM=yes and a completed Rules of Engagement file with Status: AUTHORIZED.
  • Idempotent and explicit. Re-runs do not blindly overwrite operator-filled ROE or inventory files. Configuration uses EU_* names. No secrets are hardcoded.
  • Evidence is treated as sensitive. Report directories are mode 700, report files are mode 600, and redaction runs before evidence is written. Redaction is still best-effort; review reports before sharing.
